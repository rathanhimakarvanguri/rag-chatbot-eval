# IT and Information Security Policy

Larkspur Systems is a fictional company. This handbook exists only as a demo corpus.

## Passwords and Authentication

Passwords must be at least 14 characters long. Multi-factor authentication is mandatory for email, VPN and the code repository. Passwords must never be shared, including with IT support staff.

## Company Devices

Every employee receives a company laptop. Laptops are refreshed every 4 years, or every 3 years for engineering roles. Full-disk encryption must remain enabled, and IT pushes operating system updates that must be installed within 7 days.

## Personal Devices

Personal phones may be used for email and chat only after installing the company's mobile device management profile. Personal laptops must never be used to access source code or customer data.

## Reporting Incidents

Lost or stolen devices must be reported to the security team within 1 hour by emailing security@larkspur.example or calling the 24x7 helpdesk. Suspected phishing emails should be reported with the "Report Phishing" button in the mail client.

## Software Installation

Employees may install software from the internal self-service catalogue. Anything outside the catalogue needs an IT ticket, and open-source libraries used in products must pass a licence review.

## Data Classification

Company data has four classes: Public, Internal, Confidential and Restricted. Restricted data, such as customer personal data, may only be stored in approved systems and must never be pasted into public AI tools.
